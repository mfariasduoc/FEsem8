Pixelverse

¡Bienvenido a Pixelverse! Una tienda web de videojuegos desarrollada como proyecto académico para aplicar conocimientos de desarrollo frontend.

Descripción

Pixelverse es una aplicación web que permite explorar un catálogo de videojuegos, visualizar productos y gestionar un carrito de compras. También incorpora un formulario de contacto para facilitar la comunicación con los usuarios.

Funcionalidades
Catálogo de videojuegos.
Carrito de compras.
Barra de navegación.
Formulario de contacto.
Interfaz web adaptable y fácil de utilizar.
Tecnologías utilizadas
React
TypeScript
Vite
CSS
JavaScript
npm
Instalación y ejecución
1. Clonar el repositorio
git clone https://github.com/mfariasduoc/FEsem8.git

2. Entrar al proyecto
cd FEsem8

3. Instalar las dependencias
npm install

4. Ejecutar el proyecto
npm run dev


Abre en tu navegador la dirección local que aparecerá en la terminal, normalmente http://localhost:5173/FEsem8/.

Compilar para producción

Para generar la versión de producción, ejecuta:

npm run build
